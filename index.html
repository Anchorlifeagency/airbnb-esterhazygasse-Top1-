🌡️ Floor Heating (COSMO Thermostat)

Winter Only: Use AC for cooling in summer. Do not alter settings in summer.
  1. Set Temp: Tap ▲ / ▼ buttons, then press ✔ to confirm.
  2. Manual Mode: If auto mode overrides settings, press Mode until the Hand icon (✋) appears.
  3. Heater Active: Small radiator icon indicates active heating.

🧺 Washer-Dryer (Bosch Quick Guide)

  • Wash Only: Power ➔ Select program ➔ Add detergent (i-DOS auto-doses) ➔ Start.
  • Wash & Dry in One Go: Power ➔ Select wash program ➔ Press Wash&Dry ➔ Select target (Cupboard dry) ➔ Start.
  • Dry Only: Power ➔ Press Dry ➔ Select target ➔ Start.
